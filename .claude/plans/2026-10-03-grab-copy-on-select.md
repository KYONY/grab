### Step 6: Mouse monitor and capture coordinator
**Status:** done
**Started:** 2026-10-03
**Completed:** 2026-10-03
**Files:**
- Create: `Grab/System/MouseMonitor.swift`
- Create: `Grab/Core/CaptureCoordinator.swift`
- Test: `GrabTests/CaptureCoordinatorTests.swift`

1. `MouseMonitor` — `NSEvent.addGlobalMonitorForEvents(matching: [.leftMouseDown, .leftMouseDragged, .leftMouseUp])` [DECISION]; records down point and `roleAt(downPoint)`, accumulates drag distance, emits a gesture on mouse-up with `clickCount`.
2. `CaptureCoordinator` (dependencies injected via protocols: settings, frontmost-app provider, `SelectionReading`, copy keystroke, pasteboard, clock/scheduler, flash callback). On a gesture:
   1. Stop if `!isEnabled`, Accessibility not trusted, or frontmost bundle ID is excluded.
   2. Stop unless `SelectionGesture.classify` is true.
   3. After a 60 ms delay (selection settles) [DECISION], read `selectedText(pid:)` and apply `CaptureStrategy`.
   4. `.write(text)` → `ClipboardFilter` → `PasteboardWriter.write` → flash.
   5. `.fallbackCopy` → remember `changeCount`, `CopyKeystroke.post()`, after 150 ms [DECISION]: if `changeCount` unchanged → nothing; if changed → read the new string, run `ClipboardFilter` against the previous string; on pass re-write it through `PasteboardWriter` (plain text + marker) and flash; on fail leave it.
3. Tests with fakes and an immediate scheduler: disabled → no write; excluded app → no write; `.empty` → no ⌘C; `.unsupported` → ⌘C posted; ⌘C with unchanged `changeCount` → no flash; duplicate text → no write; happy path → write + flash.
