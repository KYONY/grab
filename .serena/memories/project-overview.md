# Grab — project overview

macOS 27+ menu-bar-only app (MenuBarExtra, no Dock icon) that copies mouse-selected text to the clipboard (copy-on-select).
- Gestures: forward drag (>=4 pt), double-click, triple-click; keyboard selections ignored.
- Drag direction (SelectionGesture.isForward, global coords, y grows down): if |dy| > 8 pt (sameLineTolerance) forward = ends lower; else forward = ends to the right. Backward drags (right-to-left or upward) only select, no copy. No settings toggle.
- Reads selection via Accessibility (AX); falls back to sending Cmd+C, except when a list/table/outline has focus; restores previous clipboard if fallback copied text that would be skipped.
- Exclude list by bundle ID (defaults: terminals, Finder, 1Password, Keychain Access).
- Writes plain text tagged `org.nspasteboard.AutoGeneratedType` (PasteboardWriter.autoGeneratedType).
- Localization: en (source) + uk in Grab/Localizable.xcstrings. No third-party deps. Needs Accessibility permission.

## Layout
- Grab/GrabApp.swift — @main App; AppModel (settings, permission, coordinator, mouse monitor, icon flash, onboarding window); AppDelegate
- Grab/Core/CaptureCoordinator.swift — handles a gesture: exclude/trust checks, AX read, fallback, pasteboard write
- Grab/Core/CaptureStrategy.swift — AXReadResult/CaptureAction decision, FallbackGuard
- Grab/Core/ClipboardFilter.swift — skip rules (empty, single char, already on clipboard)
- Grab/Core/SelectionGesture.swift — classifies mouse events into selection gestures
- Grab/System/AccessibilityReader.swift — SelectionReading via AX API
- Grab/System/CopyKeystroke.swift — synthesizes Cmd+C
- Grab/System/LoginItem.swift — launch at login
- Grab/System/MouseMonitor.swift — global mouse monitor, emits MouseGesture
- Grab/System/PasteboardWriter.swift — plain text + AutoGeneratedType marker
- Grab/System/PermissionMonitor.swift — Accessibility trust state
- Grab/System/RunningApps.swift — running apps list for Exclude picker
- Grab/Settings/SettingsStore.swift — persisted settings (enabled, excludes)
- Grab/Settings/DefaultExcludes.swift — default excluded bundle IDs
- Grab/UI/MenuContent.swift, OnboardingView.swift, SettingsView.swift, StatusIcon.swift — menu, permission onboarding, settings window, icon state
- GrabTests/ — unit tests per component (AccessibilityReader, CaptureCoordinator, CaptureStrategy, ClipboardFilter, PasteboardWriter, PermissionMonitor, SelectionGesture, SettingsStore, StatusIcon, Smoke)

## Commands
- `make build` — xcodebuild Debug into build/
- `make test` — scripts/check-localization.sh (every key has uk translation) + xcodebuild test
- `make run` — build and open build/Build/Products/Debug/Grab.app
- `make clean`
