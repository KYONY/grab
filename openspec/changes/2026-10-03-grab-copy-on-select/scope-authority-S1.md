## In-scope set
- menu-bar-only app (LSUIElement), name Grab, bundle id com.pryima.grab
- copy mouse selection to clipboard when enabled, except apps in Exclude list (blacklist)
- gestures: drag >= 4 pt, double click, triple click; no keyboard selection
- role check at mouse-down (text roles or unknown proceed)
- capture: Accessibility API first; synthesized Cmd+C only when AX unsupported; empty = skip; changeCount check
- clipboard: overwrite, plain text, skip empty/duplicate/<2 chars, org.nspasteboard.AutoGeneratedType marker
- exclude list by bundle id; add from running apps or .app picker; defaults: terminals (agterm, Ghostty, Terminal, iTerm2), Finder, 1Password, Keychain Access, Grab
- feedback: menu bar icon flash ~0.3 s; no sound/HUD
- permission onboarding window, deep link to Accessibility settings, 1 s AXIsProcessTrusted polling, warning icon, disabled toggle
- menu: enable toggle, Settings…, Quit; icon reflects on/off/no-permission
- settings: Exclude list, launch at login (SMAppService)
- persistence in UserDefaults; enabled after first install
- localization: English + Ukrainian (String Catalog), system language
- Swift + SwiftUI, macOS 27, no third-party dependencies
- Xcode project (no xcodegen), xcodebuild + make run, signed with Apple Development cert
- unit tests on pure logic; manual checks in Safari, Notes, VS Code, Slack, Finder, agterm
- personal use only; architecture must not block a later Developer ID build

## Out of scope
- global hotkey; App Store; notarization now; keyboard selection; per-app fallback toggle; rich text; sound/HUD
